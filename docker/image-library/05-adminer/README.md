# 05. Adminer (альтернатива phpMyAdmin)

> **Важно:** для реального запуска необходим Docker. В этой среде Docker отсутствует:
> команды ниже — готовые инструкции, а не выполненные действия; значения в разделе
> «Результаты» — плейсхолдеры, которые заполняются после запуска на вашей машине.

> ## ⚠️ Предупреждение
>
> Без отдельно запущенного контейнера с БД админ-панель не сможет подключиться. Данные формы заполнять не требуется.

> Следуйте инструкции источника и запускайте только в изолированном окружении.

## 🧰 Что за образ

Веб-интерфейс администрирования баз данных. Для реальной работы требует отдельного контейнера с БД и связи с ним.

- **Образ(ы):** `adminer:latest`

### Порты

| Порт хоста | Порт контейнера | Назначение |
|---|---|---|
| `8084` | `8080` | основной Adminer |
| `8085` | `8080` | второй экземпляр adminer_2 |

### Переменные окружения

Не используются.

## 🧰 Предварительные требования

- WSL, другой полноценный Linux либо Git-Bash/Linux/Mac; для части команд — Windows PowerShell.
- Свободные порты из таблицы выше (проверять до запуска).
- Рекомендуется начать с «чистого листа»: остановить и удалить ненужные учебные контейнеры и образы.
- Никогда не используйте русские имена файлов/каталогов, пробелы и спецсимволы в путях проекта.

```shell
docker version
docker ps -a
```

## 📋 Пошаговое выполнение

### 1. Загрузка образа

```shell
docker pull adminer:latest
```

### 2. Запуск в Git-Bash/Linux/WSL/Mac

```shell
docker run -d \
  --name adminer \
  -p 8084:8080 \
  adminer:latest
```

### 3. Вариант для Windows PowerShell

```shell
docker run -d `
  --name adminer `
  -p 8084:8080 `
  adminer:latest
```

### 4. Проверка работы

```shell
docker ps
curl http://localhost:8084/
# или открыть http://localhost:8084 в браузере
```

### 5. Второй экземпляр из того же образа

```shell
docker run -d \
  --name adminer_2 \
  -p 8085:8080 \
  adminer:latest
# http://localhost:8085
```

### 6. Пример параметров подключения к PostgreSQL (если БД запущена)

```text
Система: PostgreSQL
сервер: host.docker.internal
логин: postgres
пароль: mysecretpassword
```

### Очистка контейнера

```shell
docker stop adminer adminer_2 || true
docker rm -f adminer adminer_2 || true
```

## ✅ Проверка работы (кратко)

- `docker ps` — контейнер в статусе `Up` (для `--rm`-контейнеров проверка во время работы).
- `curl <адрес>` или браузер — страница/ответ сервиса.
- `docker logs <имя>` — отсутствие ошибок в логах.
- `docker exec -it <имя> ...` — проверка изнутри контейнера (где предусмотрено заданием).
