# 07. Статический сайт на Apache

> **Важно:** для реального запуска необходим Docker. В этой среде Docker отсутствует:
> команды ниже — готовые инструкции, а не выполненные действия; значения в разделе
> «Результаты» — плейсхолдеры, которые заполняются после запуска на вашей машине.

## 🧰 Что за образ

Раздача статического сайта с монтированием каталога хоста в Apache. Файл site/index.html редактируется на хосте, а не внутри контейнера.

- **Образ(ы):** `httpd:alpine`

### Порты

| Порт хоста | Порт контейнера | Назначение |
|---|---|---|
| `8081` | `80` | статический сайт |

### Переменные окружения

Не используются.

## 🧰 Предварительные требования

- WSL, другой полноценный Linux либо Git-Bash/Linux/Mac; для части команд — Windows PowerShell.
- Свободные порты из таблицы выше (проверять до запуска).
- Рекомендуется начать с «чистого листа»: остановить и удалить ненужные учебные контейнеры и образы.
- Никогда не используйте русские имена файлов/каталогов, пробелы и спецсимволы в путях проекта.

```shell
docker version
docker ps -a
```

## 📋 Пошаговое выполнение

### 1. Подготовка каталога сайта

```shell
# каталог site/ и файл site/index.html уже созданы в этом задании
cd site
ls -la
# при необходимости: echo '<h1>Hello Docker!</h1>' > index.html
```

### 2. Проверка порта и запуск с монтированием (Git-Bash/Linux/WSL/Mac)

```shell
netstat -tuln | grep :8081 || true
docker pull httpd:alpine
docker run -d \
  --name my-apache-site \
  -p 8081:80 \
  -v "$(pwd)":/usr/local/apache2/htdocs \
  httpd:alpine
```

### 3. Вариант для Windows PowerShell

```shell
docker run -d `
  --name my-apache-site `
  -p 8081:80 `
  -v ${PWD}:/usr/local/apache2/htdocs `
  httpd:alpine
```

### 4. Проверка работы

```shell
curl http://localhost:8081/
# или открыть http://localhost:8081 в браузере (Ctrl+R / Ctrl+Shift+R при кэше)
```

### 5. Изменение содержимого

```text
Отредактируйте site/index.html в VS Code на хосте и обновите страницу в браузере.
```

### Очистка контейнера

```shell
docker stop my-apache-site || true
docker rm -f my-apache-site || true
```

## ✅ Проверка работы (кратко)

- `docker ps` — контейнер в статусе `Up` (для `--rm`-контейнеров проверка во время работы).
- `curl <адрес>` или браузер — страница/ответ сервиса.
- `docker logs <имя>` — отсутствие ошибок в логах.
- `docker exec -it <имя> ...` — проверка изнутри контейнера (где предусмотрено заданием).
