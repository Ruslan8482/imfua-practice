## 📋 Сборка и запуск

```bash
cd docker/dockerfile/08-cpp-ftxui-wow
docker build -t imfua-ftxui-wow .
docker run -it --rm imfua-ftxui-wow
```

FTXUI загружается на этапе сборки через `FetchContent` — нужен доступ к сети.

## ✅ Проверка

В терминале появится рамка с надписью `Hello from FTXUI!` и анимированной шкалой.
Нажмите `Exit` или `Ctrl+C` для выхода.

## 🧰 Порты

Порты не используются (консольный TUI).

Исходник из источника сохранён полностью; единственная адаптация — фоновый поток
останавливается через `std::atomic<bool>` и `join()` вместо `detach()`, чтобы исключить
обращение к уже разрушенному экрану. Это не скелет, а рабочий код.
