и результат в этом каталоге.

## Сборка и запуск

```bash
cd docker/dockerfile/18-cpp-qt6
docker build -t imfua-qt6 .
```

Linux / WSLg:

```bash
docker run -it --rm \
  -e DISPLAY=$DISPLAY \
  -v /tmp/.X11-unix:/tmp/.X11-unix:rw \
  imfua-qt6
```

Если окно не появилось: `xhost +local:docker`.

## Проверка

Должно появиться окно `400x200` с надписью `Привет из Docker-контейнера с Qt6!`
и кнопкой `Нажми меня`.

## Порты

Порты не используются; нужен X11-сокет хоста. Задание рекомендуется выполнять в WSL/Ubuntu.

Код из источника сохранён полностью; скелет не потребовался. Список X11-пакетов
сокращён донеобходимых для Qt6 xcb-платформы, лишние -dev-пакеты удалены.
