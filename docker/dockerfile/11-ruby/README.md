# 11. Dockerfile. Приложение на Ruby

## Цель

Собрать и запустить учебный образ по инструкции источника, зафиксировать команды
и результат в этом каталоге.

## Источник

- Оригинал: [Ruby.md](https://github.com/rurewa/imfua/blob/main/content/Docker/Dockerfile/Ruby.md)
- Реестр заданий: [TASKS.md](../../../TASKS.md)

## Структура каталога

```text
11-ruby/
├── Dockerfile
├── .dockerignore
├── README.md
├── commands.sh
├── Gemfile
└── app.rb
```

## Сборка и запуск

```bash
cd docker/dockerfile/11-ruby
docker build -t imfua-ruby .
docker run -it --rm imfua-ruby
```

## Проверка

При наличии сети выведется случайный факт о котах, например:
`🐱 Случайный факт о котах: A cat's tail can contain up to 20,000 hairs.`
Если сервис недоступен, приложение напечатает сообщение об ошибке — сборка от этого не зависит.

## Порты

Порты не используются; во время выполнения нужен HTTPS-доступ к `catfact.ninja`.
