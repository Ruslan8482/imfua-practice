## Сборка и запуск

```bash
cd docker/dockerfile/07-cpp-ftxui
docker build -t imfua-ftxui .
docker run -it --rm imfua-ftxui
```

Сборка загружает FTXUI v5.0.0 через `FetchContent`, поэтому нужен доступ к сети;
запуск требует интерактивного терминала (`-it`).

## Проверка

Выберите стрелками пункт меню и нажмите Enter. После выхода появится
`Вы выбрали пункт N`. Для исследования образа:

```bash
docker run -it --rm --entrypoint bash imfua-ftxui
```

## Порты

Порты не используются (консольный TUI).

Исходный код `main.cpp` и `CMakeLists.txt` взят из источника полностью; скелет не требуется.
